# 1 — نظرة عامة على القسم

**الرابط الرسمي:**  
<span dir="ltr">https://www.elastic.co/docs/deploy-manage/deploy/cloud-on-k8s/manage-deployments</span>

## ما هو ECK؟

<span dir="ltr">Elastic Cloud on Kubernetes (ECK)</span> يعني: تشغيل منتجات Elastic (أهمها <span dir="ltr">Elasticsearch</span> و<span dir="ltr">Kibana</span>) داخل كلاستر <span dir="ltr">Kubernetes</span> عبر **مشغّل (Operator)**.

أنت لا تدير كل <span dir="ltr">Pod</span> يدوياً؛ تكتب **مواصفة مرغوبة** في ملف <span dir="ltr">YAML</span> (أو قيم <span dir="ltr">Helm</span>)، والمشغّل يخلق ويحدّث موارد الكلاستر حتى يطابق طلبك.

## معنى «deployment» في هذا القسم

هنا **deployment** = **كلاستر Elasticsearch**، ويمكن أن يكون معه **واحدة أو أكثر من حالات Kibana** متصلة بنفس الكلاستر.

هذا **مختلف** عن نوع المورد في Kubernetes اسمه <span dir="ltr">Deployment</span> — لا تخلط بين الاثنين.

## ماذا يغطي القسم وماذا لا يغطي؟

| يغطي | لا يغطي (قسم آخر) |
|------|-------------------|
| نشر وضبط <span dir="ltr">Elasticsearch</span> و<span dir="ltr">Kibana</span> | <span dir="ltr">APM Server</span>، <span dir="ltr">Beats</span>، <span dir="ltr">Elastic Agent</span>، <span dir="ltr">Logstash</span>، <span dir="ltr">Maps Server</span> |
| التحديث والتوسع والوصول | تثبيت وترقية **ECK Operator** نفسه (قسم upgrade للمشغّل) |

للتطبيقات الأخرى ابحث في التوثيق عن: **Orchestrating other Elastic Stack applications**.

## ما الذي «ستتعلمه» حسب التوثيق؟

1. **نشر كلاستر Elasticsearch** — تعريف مورد <span dir="ltr">Elasticsearch</span> في الكلاستر.
2. **نشر Kibana** — مورد <span dir="ltr">Kibana</span> مع <span dir="ltr">elasticsearchRef</span> للربط.
3. **الإدارة عبر Helm** — chart <span dir="ltr">eck-stack</span> لتجميع المكونات.
4. **تطبيق التحديثات** — تعديل النشر الحالي بأقل توقف ممكن.
5. **ضبط الوصول** — خدمات Kubernetes، كلمات المرور، الشهادات.
6. **إعدادات متقدمة** — تخزين، شبكة، أمان، توسع.
