## Users and roles — المستخدمون والأدوار

- ECK يدير **بيانات اعتماد** (مثل مستخدم <span dir="ltr">elastic</span>).
- يمكن إنشاء **مستخدمين مخصصين** وضبط **realms** للمصادقة (LDAP، SAML، … حسب إعداد Elasticsearch).
- الهدف: من يدخل للكلاستر وKibana وبأي صلاحيات.

## Customize Pods — تخصيص `podTemplate`

حقل <span dir="ltr">podTemplate</span> يمرّر مواصفة Pod عادية في Kubernetes:

- labels و annotations
- <span dir="ltr">affinity</span> / <span dir="ltr">tolerations</span>
- حاويات إضافية، <span dir="ltr">initContainers</span>
- **resources** (CPU/RAM)

يُستخدم في Elasticsearch (تحت <span dir="ltr">nodeSets</span>) وفي Kibana وغيرها.

---

## Manage compute resources — CPU والذاكرة

في الإنتاج **يجب** تحديد:

- <span dir="ltr">requests</span> — الحد الأدنى لجدولة Pod
- <span dir="ltr">limits</span> — الحد الأقصى (خصوصاً الذاكرة)

المشغّل يضع افتراضيات مناسبة للتجربة؛ غيّرها للإنتاج.

| مفهوم | معنى عملي |
|--------|-----------|
| <span dir="ltr">limits.memory</span> | يحدد ذاكرة JVM في Elasticsearch تلقائياً (heap) |
| CPU منخفض جداً في <span dir="ltr">limits</span> | Kubernetes يخنق الحاوية → أداء سيء |
| <span dir="ltr">requests == limits</span> | QoS <span dir="ltr">Guaranteed</span> — أقل طرد للـ Pod عند ضغط الموارد |

تجاوز heap يدوياً: متغير <span dir="ltr">ES_JAVA_OPTS</span> في <span dir="ltr">podTemplate</span>.

## Recipes — أمثلة متقدمة

مستودع GitHub لـ ECK يحتوي **recipes** جاهزة (سيناريوهات حقيقية). تُنسخ وتُعدّل — ليست جزءاً من المشغّل نفسه.

## Connect to external Elastic resources

إذا Elasticsearch **ليس** على ECK لكن Kibana عليه (أو العكس):

- استخدم <span dir="ltr">elasticsearchRef</span> / <span dir="ltr">kibanaRef</span> مع **Secrets** مخصصة للاتصال.
- مفيد للهجين أو مراقبة كلاستر خارجي.

---

## Secure settings — الإعدادات الآمنة

إعدادات حساسة (كلمات مرور API، مفاتيح) تُخزن في **keystore** وليس في YAML مكشوف:

- Elasticsearch و Kibana يدعمان تمريرها عبر **Kubernetes Secrets**
- راجع صفحات **Secure settings** في توثيق ES/Kibana

## Kibana encryption keys

في الإنتاج يُنصح بضبط مفاتيح تشفير Kibana. ECK يولّدها تلقائياً؛ يمكن استبدالها عبر **Secure settings**.
